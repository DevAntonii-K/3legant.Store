# 3legant.Store — E-commerce Landing Page

Modern responsive landing page for a headphone store with a focus on clean UI, product presentation, and mobile-first design.

---

## 🔗 Links

🌐 Live site: https://devantonii-k.github.io/3legant.Store/  
📦 GitHub: https://github.com/DevAntonii-K/3legant.Store

---

## 📌 About the Project

3legant.Store is a fully responsive e-commerce landing page built with semantic HTML, modular SCSS, and vanilla JavaScript.

The project simulates a real online store interface with product sections, promotional banners, and interactive UI elements.

---

## ✨ Key Features

### 🧭 Navigation
- Responsive header with desktop and mobile layouts
- Burger menu with slide-in drawer navigation
- Overlay system for mobile UX

### 🛍 Product Presentation
- “New Arrivals” Swiper slider
- “Best Sellers” responsive grid layout
- Product cards with hover animations and badges (NEW / HOT)

### 🎯 Promotional UI
- Hero section with strong marketing CTA
- Discount section with countdown timer
- Promotional banners with adaptive images (desktop/mobile switching)

### 📱 Fully Responsive Design
- Mobile-first layout approach
- Multiple breakpoints (1025px / 769px / 426px / 321px)
- Flexible grid + flex system for all sections
- Adaptive typography and spacing

### 🎨 UI/UX Details
- Smooth hover effects (scale, opacity, transitions)
- Text truncation with ellipsis for long product names
- Reusable design system (colors, fonts, spacing variables)
- Consistent component-based BEM architecture

### 📬 Newsletter Section
- Simple email subscription UI
- Clean CTA design

### ⚡ Performance & Structure
- SCSS modular architecture (base + blocks system)
- Optimized image handling (WebP + fallback)
- Reusable utility classes
- Clean separation of components

---

## 🧱 Tech Stack

- HTML5 (semantic layout)
- SCSS (BEM methodology)
- JavaScript (vanilla)
- Swiper.js
- Gulp (task runner for SCSS compilation & build automation)

---

## 🎯 What I Practiced

- Real-world landing page structure
- Responsive UI design from Figma-like layout
- Component-based SCSS architecture
- Mobile navigation systems (drawer menu)
- Product grid + slider logic
- UI interaction design (hover states, overlays, timers)
